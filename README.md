# Moss & der falsche Pfad

Ein eigenständiger HTML5-Canvas-Präzisions-Plattformer, inspiriert vom überraschenden Raumdesign klassischer Troll-Plattformer. Alle 30 Räume sind von Hand gebaut und besitzen eine eigene Geometrie oder Fallenidee.

## Spielen

`index.html` direkt öffnen oder den Ordner über einen beliebigen lokalen Webserver bereitstellen.

## Steuerung

- `A` / `D` oder `←` / `→`: bewegen
- `W`, `↑` oder Leertaste: springen
- `R`: Raum neu starten
- `M`: Ton umschalten
- `Esc`: Raumauswahl schließen

Touch-Tasten werden auf Smartphones, Tablets und anderen Geräten mit Touch-Eingabe automatisch eingeblendet. Externe Tastaturen funktionieren auch auf iPadOS. Fortschritt und Tonstatus werden lokal im Browser gespeichert.

## Leveldesign

Die Räume kombinieren verzögerte Stacheln, bröckelnde Böden, fallende Deckenblöcke, bewegte Plattformen, Pendelsägen, Schubwände, falsche Türen, fliehende Ziele, Dunkelheit und Wrap-around-Wege. Schnelle Neustarts halten Versuch und Lernen unmittelbar zusammen.
