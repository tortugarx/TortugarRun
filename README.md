# Riftstep

Ein eigenständiger HTML5-Canvas-Präzisions-Plattformer mit überraschenden Fallen und Fokus-Mechanik.

## Spielen

`index.html` direkt öffnen oder lokal einen Webserver starten:

```bash
python3 -m http.server 8080
```

Dann `http://localhost:8080` öffnen.

## Steuerung

- `A` / `D` oder Pfeiltasten: bewegen
- `W`, `↑` oder Leertaste: springen
- `F` oder linke Umschalttaste: Fokus-Impuls
- `R`: Raum neu starten
- `M`: Ton umschalten

Auf Touch-Geräten werden Bildschirmtasten eingeblendet.
